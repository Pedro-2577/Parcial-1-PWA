# Aplicación del clima

Aplicación web progresiva para consultar el estado meteorológico actual de una ciudad. La interfaz prioriza una consulta rápida, datos legibles y una experiencia responsive.

## Funcionalidades

- Búsqueda de ciudades mediante geocodificación.
- Temperatura, sensación térmica, humedad y viento.
- Estado meteorológico traducido a etiquetas claras.
- Integración con Open-Meteo, sin API key expuesta.
- Interfaz adaptable a móvil y escritorio.
- Enlace de retorno al portfolio.

## Stack

- HTML
- CSS
- JavaScript
- Open-Meteo API
